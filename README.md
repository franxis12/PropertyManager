# Dependencies on this project

• React router dom - npm install react-router-dom

• React Hook Form – npm install react-hook-form zod @hookform/resolvers

• Tailwind CSS - npm install tailwindcss @tailwindcss/vite

• Tanstask – npm install @tanstack/react-query

• Supabase – npm install @supabase/supabase-js

• Days – npm install dayjs

• Sonner – npm install sonner
